# LA-01 Lieferanten-Agent, Kostenspanne und Hilfe

Version 1.0 · Kapitel 5 · Paket K5-e · baut auf LP-01, DL-01, MA-01, WK-01 · ersetzt KI-23 Hilfe für Lieferanten · Bildvorlagen: L5-Deal-Mappe, L5-Akte-Privat, L5-Heute, L5-Beitrag · KN-48, KN-49, KN-50

> **Klärungen aus K0 (24.11.2026, `docs/entscheidungen.md`):** Beträge in Cent mit Währung (E-K0-10).

## Ziel

Der Agent des Lieferanten arbeitet für den Lieferanten: Er rechnet die Reibung eines Kunden aus den eigenen Fertigungsdaten, schlägt Deals vor und nimmt Routinearbeit ab. Was davon in die Mitte geht, entscheidet ein Mensch.

## Grundsätze

- Der Agent sieht immer nur eine Akte: `shared` und `supplier_private` dieser Beziehung. Er sieht nie die Seite des Kunden.
- Untergrenze, Marge und Herleitung bleiben in `supplier_private`, auch im Simulator (SI-01).
- Zusagen, Preise und Freigaben gibt immer ein Mensch.

## Reibung beim Lieferanten (KN-48)

Nach dem Import der Fertigungsdaten erkennt der Agent Eilabrufe (Abruf mit weniger als 10 Tagen Vorlauf) und bewertet sie je Kostenart mit Quelle: Sonderschichten (Fertigungsdaten), Expressfracht (Rechnungen Spedition), Rüsten und Ausschuss (Fertigungsdaten). Ergebnis als Spanne. Demo: 23 Eilabrufe in 12 Monaten; 38–52 + 18–26 + 14–22 T€, gerundet ≈ 70 bis 100 T€. Ist die Reibung höher als ein möglicher Nachlass, entsteht die Mappe „Deal für <Kunde> vorschlagen“ (Vorschlagen) mit Optionen, Wert für beide Seiten und eigener Untergrenze (Demo: A 1,5 % gegen 6 Monate, B gegen 3 Monate = Untergrenze, C abwarten).

## Kostenspanne (KN-49)

- Schalter „Kostenspanne teilen“ in der Deal-Mappe; freiwillig, nur durch einen Menschen. Der Kunde sieht nur die Spanne, nie Herleitung, Marge oder Untergrenze.
- Die Spanne erscheint in der Mitte am Deal und unter „Von <Lieferant>“ in der Akte des Kunden. Jedes Teilen steht im Verlauf.
- Zurückziehen nimmt die Spanne aus der Mitte. Was der Kunde damit schon gerechnet hat, bleibt bei ihm, wird aber als „Spanne zurückgezogen“ markiert; neue Bewertungen rechnen wieder mit Branchenwerten (E-K5-4).

## Vorlagen (E-K5-5, einzeln entschieden)

Der Lieferant darf eigene Vorlagen wiederverwenden: Aufbau und Text eines Vorschlags. Eine Vorlage enthält nie Konditionen, Mengen, Kosten oder andere Daten aus einer Kundenakte. Beim Einsetzen füllt Reziproq sie nur mit Daten der geöffneten Akte. Jeder Vorschlag wird je Akte einzeln gesendet; es gibt keinen Serienversand. Speichern einer Vorlage aus einem Vorschlag entfernt alle Werte und Bezüge; der Nutzer sieht vor dem Speichern, was entfernt wird.

## Hilfe (KN-50)

Entwürfe in Kurz prüfen (Vorbereiten): Antworten im Ton der eigenen Mails, Meldungen (Liefertreue aus Lieferscheinen), Zusammenfassung von Feedback, Formulare und Selbstauskünfte aus eigenen Unterlagen mit Fundstelle (Demo: Halder, 31 von 34 Fragen), Beiträge zum Termin (BE-01). Hilfen am Entwurf: kürzer, Englisch, Begründung. Senden durch einen Menschen.

## Stufen (Mein Agent beim Lieferanten)

| Aufgabe | Standard |
|---|---|
| Mails des Kunden zuordnen | Erledigen |
| Antworten entwerfen | Vorbereiten |
| Reibung bewerten, Deals vorschlagen | Vorschlagen |
| Formulare und Selbstauskünfte | Vorbereiten |
| Verhandeln in Anfragen (ab Kapitel 8) | aus; zugelassen: Erledigen, nur unverbindlich innerhalb der eigenen Untergrenze, höchstens 3 Runden (VG-01) |

Obergrenzen wie MA-01; verdiente Autonomie nach AU-01.

## Daten

```sql
CREATE TABLE cost_range (
  id uuid PRIMARY KEY, relationship_id uuid, deal_id uuid,
  low numeric, high numeric, unit text DEFAULT 'EUR/Jahr',
  shared_by uuid, shared_at timestamptz, withdrawn_by uuid, withdrawn_at timestamptz,
  space text NOT NULL DEFAULT 'shared');

CREATE TABLE supplier_friction (        -- Herleitung, nur Lieferant
  id uuid PRIMARY KEY, relationship_id uuid, period daterange, events int,
  parts jsonb,                          -- je Kostenart: low, high, Quelle
  low numeric, high numeric, floor_terms jsonb,
  space text NOT NULL DEFAULT 'supplier_private');

CREATE TABLE supplier_template (
  id uuid PRIMARY KEY, supplier_org_id uuid, title text,
  structure jsonb,                      -- Abschnitte und Platzhalter, keine Werte
  body text, created_by uuid, created_at timestamptz,
  space text NOT NULL DEFAULT 'supplier_private');
```

Eine Prüfung beim Speichern weist jede Vorlage zurück, deren `structure` oder `body` Zahlen mit Einheit, Teilenummern, Namen von Kunden oder Bezüge auf Objekte einer Akte enthält.

## Werkzeuge

`supplier.friction_cost` (Erledigen, privat) · `deal.draft_offer` (Vorbereiten) · `cost_range.share` / `cost_range.withdraw` (nur Mensch; Teilen ist Freigabe in die Mitte) · `template.save` / `template.apply` (Mensch; Füllung nur aus der geöffneten Akte) · `help.draft` (Vorbereiten).

## Fertig, wenn

- [ ] T5-20 Die Kostenspanne erscheint erst nach dem Schalter; Zurückziehen nimmt sie aus der Mitte.
- [ ] T5-LA1 Nach dem Zurückziehen ist die Bewertung des Kunden als „Spanne zurückgezogen“ markiert; neue Bewertungen rechnen mit Branchenwerten.
- [ ] T5-LA2 Eine Vorlage enthält keine Werte aus einer Kundenakte; angewendet in Akte B enthält sie nur Daten aus Akte B; es gibt keinen Versand an mehrere Akten.
- [ ] T5-LA3 Herleitung, Marge und Untergrenze stehen in keiner Zeile mit `space = shared` und erscheinen nie beim Kunden, auch nicht im Simulator.
- [ ] T5-LA4 Eine vorausgefüllte Selbstauskunft nennt je Antwort die Fundstelle; offene Fragen bleiben leer und markiert.
