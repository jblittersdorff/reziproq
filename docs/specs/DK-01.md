# DK-01 Deck und Prüfung vor dem Teilen

Version 1.0 · Kapitel 3 · Paket K3-d · baut auf TE-01, BE-01, KI-18 · ersetzt J-Upload, J-Teilen (Teile), Vorher-J-Deck · Bildvorlagen: J-Deck, J-Moderation

> **Klärungen aus K0 (24.11.2026, `docs/entscheidungen.md`):** Der Dialog „So teilen“ ist erlaubt (E-K0-01).

## Ziel

Nach der Beitragsfrist baut Reziproq die Präsentation selbst. Vor dem Teilen prüft es, dass nichts Privates darin steht.

## Ablauf

1. **Bauen.** Nach `contributions_due` baut Reziproq das Deck als Entwurf (Aufgabe „Deck bauen“, Erledigen für das Bauen; E-K3-3): eine Folie je Agendapunkt plus Titel und Zusagen, Diagramme aus Standardtypen, Quelle je Folie, Beiträge eingesetzt, fehlende als Lücke markiert, Sprechernotizen privat.
2. **Uploads.** Hochgeladene Dateien werden dem passenden Punkt zugeordnet (KI-18, Erledigen) und als Seiten eingefügt; Text und Fundstellen sind in Frag Reziproq findbar.
3. **Prüfen.** Vor dem Teilen läuft die Prüfung: Euro-Werte, Ziele, interne Notizen, Schätzungen für das Gegenüber, Mandatsangaben. Treffer stehen mit Folie und Fundstelle in einer Liste; das Teilen ist erst möglich, wenn jeder Treffer entfernt oder bewusst freigegeben ist (bindend).
4. **Teilen.** Ein Mensch teilt (Token). Geteilt wird eine Fassung; spätere Änderungen sind eine neue Fassung.

## Daten

```sql
CREATE TABLE deck (
  id uuid PRIMARY KEY, meeting_id uuid, version int, built_at timestamptz,
  shared_at timestamptz, check_result jsonb, space text NOT NULL DEFAULT 'buyer_private');
CREATE TABLE slide (
  id uuid PRIMARY KEY, deck_id uuid, position int, agenda_item_id uuid, kind text,
  title text, title_sources jsonb, chart jsonb, gap boolean, upload_page_ref text,
  speaker_note text, speaker_note_space text DEFAULT 'buyer_private');
```

Das geteilte Deck ist eine Kopie in `shared` ohne Sprechernotizen.

## Oberfläche

Folie: weiße Fläche 16:10, 1 px `#dfe2dd`, Quelle 12 px. Lücke: gestrichelte Fläche mit „Beitrag fehlt · <Person>“.

## Fertig, wenn

- [ ] T3-07 Ein Upload wird dem richtigen Punkt zugeordnet; der Text ist in Frag Reziproq mit Fundstelle (Folie) findbar.
- [ ] T3-08 Das Deck entsteht nach der Frist mit 11 Folien; fehlende Beiträge sind als Lücke markiert.
- [ ] T3-09 Die Prüfung vor dem Teilen findet die Euro-Werte auf Folie 3; nichts Privates steht im geteilten Deck.

## Nicht Teil

Eigene Folienvorlagen der Kunden; Export als PowerPoint ist eine spätere Funktion.
