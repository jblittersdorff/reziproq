# MS-01 Marktsignale

Version 1.0 · Kapitel 6 · Paket K6-e · baut auf ST-01, WK-01, AK-01 · ersetzt KI-08 Agent Marktanalyse (Jahresanalyse) · Bildvorlagen: K6-Signal, WG-Uebersicht, WG-Start · KN-37

> **Klärungen aus K0 (24.11.2026, `docs/entscheidungen.md`):** Beträge in Cent mit Währung (E-K0-10).

## Ziel

Preis-, Rohstoff- und Kapazitätssignale werden laufend erkannt und auf die Beziehungen einer Warengruppe abgebildet, mit Rechenweg je Beziehung. Ein Signal ändert keine Pläne direkt; es erzeugt Hinweise und Entwürfe.

## Quellen (E-K6-5, einzeln entschieden)

- MVP: nur frei nutzbare Quellen, also öffentliche Indizes und Statistiken, deren Nutzung erlaubt ist, sowie eigene Verträge und Kostenstrukturen des Kunden.
- Lizenzpflichtige Börsen- und Marktdaten erst nach dem Pilot und mit Lizenz.
- Die Demo nutzt eine synthetische Kupferkurve. Quelle in der Demo: „Kupferindex (Demo-Daten)“; keine Börse wird genannt.
- Je Quelle in den Einstellungen: Name, Nutzungsrecht, Abrufrhythmus, zuständige Person.

## Ablauf

1. Täglich 06:00 prüft der Worker die Quellen (Vorschlagen). Ein Signal entsteht, wenn eine Reihe die Schwelle der Warengruppe überschreitet (Standard: 5 % gegenüber dem Basismonat der Verträge).
2. **Abbildung je Beziehung** aus Kostenstruktur und Verträgen (Rechnung in der Wert-Engine): Wirkung, Rechenweg, Spanne, Status (`Klausel`, `Risiko`, `geschützt`, `beobachten`).
3. **Vorschläge:** Hinweis in der Akte (nur Käuferseite), Entwurf in der Strategie (Teil 2 Markt, Teil 3 Risiko, Teil 4 Umsetzung). „Vorschläge übernehmen“ schreibt die Entwürfe in die Strategie (ST-01, Fortschreiben); „Verwerfen“ mit Grund.
4. Pläne, Mandate und Deals folgen nur der freigegebenen Strategie (E-K6-4).

## Blatt „Marktsignal“ (über der Warengruppe)

Kopf (Signal, Quelle, erkannt am, Warengruppe); Satz von Reziproq mit Quellen-Chips; Was es je Beziehung bedeutet; Rechenweg; Was Reziproq vorschlägt; Vorschläge übernehmen, Verwerfen; Regel „Woher Marktsignale kommen“. Signale erscheinen auch in der Liste der Warengruppen und an der Warengruppe.

## Demo: Kupfer +8 % seit Oktober (Mo 23.11., 06:00)

Kupfer ≈ 12 % der Kosten einer Leiterplatte; +8 % ≈ 1 % Preisdruck.

| Beziehung | Wirkung | Rechenweg | Status |
|---|---|---|---|
| Rheintal Elektronik | Kupferklausel (Basis 10/2026, Schwelle 5 %) greift ab Januar mit ≈ +0,4 %, ≈ 11 T€ im Jahr | 3,1 Mio. € × 12 % × (8 − 5) % | Klausel |
| Saar Circuits | keine Klausel, Nachforderung im Q1 möglich, ≈ 15 bis 25 T€ | 2,2 Mio. € × 12 % × 8 %, Spanne für Verhandlung | Risiko |
| Moldau PCB | Festpreis bis 06/2027 | – | geschützt |
| Donau Print | läuft aus, finanziell kritisch | – | beobachten |

Vorschläge: Rheintal an Basis 10/2026 festhalten (Hinweis in der Akte); Saar Circuits Klausel in die Ausschreibung Mehrlagen (Teil 4, Entwurf); Risiko T3 „Kupfer steigt“ (Teil 3, Entwurf für Version 3). Weitere Signale in der Liste: Laminat 5 Monate Vorlauf (knapp bis März); neue Abnehmer binden Kapazität ab 2028.

## Daten

```sql
CREATE TABLE market_source (
  id uuid PRIMARY KEY, org_id uuid, name text, kind text CHECK (kind IN ('index','statistik','vertrag','demo')),
  license text NOT NULL, licensed boolean NOT NULL DEFAULT false, schedule text, owner_person_id uuid);

CREATE TABLE market_signal (
  id uuid PRIMARY KEY, source_id uuid, kind text, title text, change numeric, base_period text,
  detected_at timestamptz, category_ids uuid[],
  effects jsonb,                        -- je Beziehung: Wirkung, Rechenweg, Spanne, Status
  proposals jsonb, state text CHECK (state IN ('neu','uebernommen','verworfen')), decided_by uuid,
  space text NOT NULL DEFAULT 'buyer_private');
```

Eine Quelle mit `licensed = false` und lizenzpflichtigem `license` wird nicht abgerufen.

## Werkzeuge

`market.signal` (Vorschlagen) · `market.map_to_relationships` (Vorschlagen, Zahlen aus der Wert-Engine) · `market.accept_proposals` (Mensch). Mein Agent: neue Zeile „Marktsignale“ (Vorschlagen).

## Fertig, wenn

- [ ] T6-20 Ein Marktsignal erscheint nie beim Lieferanten und hat je Beziehung einen Rechenweg.
- [ ] T6-MS1 Ein Signal ändert keinen Plan, kein Mandat und keinen Deal; es erzeugt nur Hinweise und Entwürfe.
- [ ] T6-MS2 Eine lizenzpflichtige Quelle ohne Lizenz wird nicht abgerufen; im Demo-Mandanten heißt die Quelle „Kupferindex (Demo-Daten)“.
- [ ] T6-MS3 Ein Signal nutzt keine Daten anderer Kunden von Reziproq.

## Nicht Teil

Kostenpflichtige Datendienste vor dem Pilot; Prognosen von Rohstoffpreisen; Signale an Lieferanten.
