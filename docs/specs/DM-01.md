## Stände

„Stand laden“ lädt einen Zwischenstand eines Drehbuchs, damit ein Test oder eine Vorführung an einem Schritt neu ansetzen kann: K4 „21.12.“, K5 „vor Schritt 5“ (SI-01), K6 „nach Freigabe“, K8 „nach Runde 2“. Ein Stand entsteht aus genau den Schritten des Drehbuchs bis dahin und wird als Schnappschuss gespeichert (`demo_snapshot`: id, org_id, key, demo_now, seed_version, created_at; nur im Demo). Ändert sich der Seed, werden die Stände neu erzeugt. Laden protokolliert ein `demo_event`.
