## Ziel

Der Kunde lädt Lieferantenstamm und Spend aus seinem ERP als Excel oder CSV hoch. Reziproq ordnet Spalten zu, erkennt bekannte Lieferanten, Dubletten und Konzernverbünde und ordnet jede Spend-Zeile einer Warengruppe des Kunden zu. Was sicher ist, wird übernommen. Was unsicher ist, prüft ein Mensch in einer Warteschlange. Jede Entscheidung macht den nächsten Import besser.

## Wer darf was

| Rolle | Darf |
|---|---|
| Admin | Import anlegen, Spalten zuordnen, prüfen, übernehmen, rückgängig machen. |
| Commodity Manager | Zeilen zur Prüfung für seine Warengruppen entscheiden. |
| Käufer: alle mit Zugriff | Ergebnis eines übernommenen Imports in den bestehenden Seiten sehen. |
| Lieferant | Nie. |

Zuordnung der Lieferanten, in dieser Reihenfolge:

1. Alias: Lieferantennummer und Quellsystem sind schon bekannt.
2. Eindeutige Kennung: USt-ID oder DUNS stimmt überein.
3. Unscharf: Name, Ort und Land mit `pg_trgm`. Ab 0,92 automatisch, von 0,70 bis 0,92 zur Prüfung, darunter neuer Lieferant zur Prüfung.
4. Modell: Nur für Zeilen zur Prüfung. Ein Modell der Klasse `small` schlägt aus höchstens fünf Kandidaten einen vor oder „neu“, mit Begründung in einem Satz. Ein Vorschlag des Modells wird nie automatisch übernommen.

Konzernverbünde:

- Das Modell schlägt Verbünde vor, etwa bei gleichem Namensstamm, gleicher Domain oder gleicher Adresse.
- Ein Verbund entsteht nur nach Bestätigung durch einen Menschen.

Zuordnung zur Warengruppe:

1. Regeln aus `category_rule`, zuerst über die Materialgruppe des ERP, dann über das Konto, dann über den Text.
2. Für den Rest ordnet ein Modell der Klasse `small` im Batch zu. Es bekommt den Text der Zeile, die Materialgruppe und den Warengruppenbaum des Kunden mit Beschreibungen.
3. Das Modell darf nur eine bestehende Warengruppe wählen oder „keine passt“. Ab einer Konfidenz von 0,90 ist die Zeile `ok`, sonst `review`.

Regeln:

- Beträge, Mengen, Währungen und Daten parst nur der Code. Das Modell sieht sie, gibt sie aber nicht zurück.
- Fremdwährungen rechnet der Code mit dem Kurs des Buchungsmonats um. Fehlt der Kurs, wird die Zeile zum Fehler.
- Für die Zuordnung der Spalten bekommt das Modell nur die Überschriften und fünf Beispielzeilen. Den Vorschlag bestätigt der Admin.
- Jede manuelle Entscheidung legt einen Alias oder eine Regel an. Beim nächsten Import greift sie ohne Modell.
- Übernehmen ist eine Transaktion. Ein übernommener Import lässt sich 30 Tage lang rückgängig machen (`reverted`). Danach nicht mehr, wenn Folgedaten auf ihn verweisen.
- Eine Datei mit demselben `file_hash` wird nicht zweimal übernommen.
- Ein Import ist ein Lauf des Agenten `import_assist` (KI-04), damit Kosten und Schritte nachvollziehbar sind.

| Einstellung des Agenten | Wert |
|---|---|
| Auslöser | Von Hand beim Import |
| Handelt im Namen von | Person, die den Import anlegt |
| Werkzeuge | Lieferantenstamm, Aliasse, Warengruppen mit Beschreibungen, Regeln |
| Modell | `small`, im Batch |
| Budget | 5,00 € je 10.000 Zeilen, höchstens 50.000 Zeilen je Import |

## Ablauf

1. **Import** (`/einstellungen/daten/import`): eine Ringkette mit vier Schritten: Datei, Spalten, Prüfen, Übernehmen. Rechts die letzten Importe mit Stand.
2. **Datei:** Excel oder CSV hochladen, Art wählen (Lieferantenstamm oder Spend).
3. **Spalten:** Vorschlag für die Zuordnung, Pflichtfelder markiert, Vorschau mit zehn Zeilen. **Weiter** startet die Verarbeitung.
4. **Prüfen:**
   - oben drei Zahlen: sicher zugeordnet, zur Prüfung, Fehler; dazu der Anteil des Spend, der sicher zugeordnet ist;
   - darunter die Warteschlange: je Zeile Rohdaten, Vorschlag, Begründung und Knöpfe **Übernehmen**, **Anderer Lieferant**, **Neu anlegen**, **Andere Warengruppe**;
   - Mehrfachauswahl für gleiche Fälle;
   - Fehlerzeilen mit Grund und Download als CSV.
5. **Übernehmen:** Die Tinte-Karte zeigt, was übernommen wird: neue Lieferanten, Spend je Warengruppe, offene Zeilen. Übernehmen ist auch mit offenen Zeilen möglich. Diese bleiben „nicht zugeordnet“ und erscheinen als eigene Warengruppe.
6. Nach dem Übernehmen zeigt die Seite die Datenqualität: zugeordneter Spend, Lieferanten ohne Warengruppe, vorgeschlagene Konzernverbünde.

## Fertig, wenn

Je Kriterium ein Test.

- [ ] Eine Testdatei mit bekannten Lieferantennummern ordnet ohne Modellaufruf zu.
- [ ] Eine Zeile mit gleicher USt-ID, aber anderem Namen wird demselben Lieferanten zugeordnet.
- [ ] Ein Name mit Ähnlichkeit 0,80 landet zur Prüfung, nicht automatisch beim Kandidaten.
- [ ] Ein Vorschlag des Modells wird nie ohne Entscheidung eines Menschen übernommen.
- [ ] Das Modell kann keine Warengruppe zurückgeben, die der Kunde nicht hat.
- [ ] Die Summe des übernommenen Spend stimmt auf den Cent mit der Summe der Datei überein, abzüglich der Fehlerzeilen.
- [ ] Eine manuelle Entscheidung erzeugt einen Alias, und ein zweiter Import derselben Datei ordnet die Zeile ohne Prüfung zu.
- [ ] Dieselbe Datei kann nicht zweimal übernommen werden.
- [ ] Rückgängig machen stellt den Stand vor dem Import wieder her.
- [ ] Kunde A sieht weder Importe noch Aliasse noch Regeln von Kunde B.
- [ ] Der Test-Lieferant sieht nichts davon.

  privat), `pg_trgm`, `relationship_side.parent_relationship_id` für Konzernverbünde (aus Sicht des
  Käufers) und die eng gefasste Funktion `app_import_beziehung_entfernen` für das Rückgängigmachen.
- Seite `/einstellungen/daten/import` mit Liste und neuem Import; `/einstellungen/daten/import/<id>`
  mit Schrittfolge Datei, Spalten, Prüfen, Übernehmen. Link unter Einstellungen (nur Admins).
- Lieferanten: Alias (auch die eigene Lieferantennummer aus PLT-07), USt-ID oder DUNS, dann

  `small`); nur Warengruppen des Kunden, ab 0,90 sicher.

  zugeordneten Nummern an.
- Übernehmen in einer Transaktion: neue Lieferanten über den bestehenden Dienst, Spend je
  Lieferant, Jahr und Warengruppe (Quelle `import`); dieselbe Datei nur einmal. Rückgängig 30 Tage.
- Beispieldatei: `docs/beispiele/ki-15-spend.csv`.

Abweichungen und offen:

- Fremdwährungen: Es gibt noch keine Wechselkurse im System; jede Zeile in einer anderen Währung als
  EUR ist ein Fehler „Währung … ohne Kurs“. Kurse kommen mit F4.
- Der Import läuft über das Modell-Gateway (Funktion `import_assist`), nicht als eigener Agentenlauf
  unter Einstellungen › KI › Agenten; Kosten stehen dort unter der Funktion.
- Verarbeitung im Request (bis 50.000 Zeilen); ein Hintergrundjob folgt bei Bedarf.
- „Nicht zuordnen“ bei der Warengruppe wird nicht gelernt; die Zeile steht beim nächsten Import
  wieder zur Prüfung.
- Ort ist kein Feld der Organisation; die Ähnlichkeit nutzt Name und Land.
