# BE-01 Beiträge und Beitrag per Link

Version 1.0 · Kapitel 3, Lieferantensicht in 5 · Paket K3-c · baut auf TE-01, BL-01, KI-18, KI-23 · ersetzt J-Anfordern, J-Beitraege, K-Beitrag · Bildvorlagen: Termin-Briefing (Beiträge), K3-Beitrag-Mobil, L5-Beitrag

## Ziel

Jeder Agendapunkt weiß, wer was beiträgt. Was schon in Unterlagen steht, findet Reziproq; was fehlt, wird mit einer Freigabe angefragt und per Link geliefert.

## Ablauf

1. **Zuordnen.** Reziproq sucht zu jedem Punkt vorhandene Unterlagen beider Seiten (Meldungen, Berichte, Uploads) und setzt den Beitrag auf „liegt vor“ mit Fundstelle und Datum der Fundstelle (E-K3-5). Die andere Seite kann ersetzen.
2. **Anfragen.** Was fehlt, wird als Anfrage an eine Person formuliert: Frage, Felder (`form_schema`) oder Datei, Frist. Agenda und Anfragen gehen mit **einer** Freigabe raus (E-K3-2); im Dialog lassen sich Anfragen abwählen. Interne Anfragen werden Aufgaben.
3. **Beitrag per Link.** Die Person bekommt einen Link (BL-01, `purpose = contribution`), sieht nur ihre Anfragen, die Frage „wie auf Folie x“ und eine Vorschau. Nach der Frist ist der Link geschlossen.
4. **Erinnern.** 2 Tage vor der Frist erinnert Reziproq (Erledigen, rücknehmbar, gekennzeichnet).
5. **Ohne Beitrag** bleibt die Folie im Deck als Lücke (DK-01) und der Punkt wird im Termin geklärt.

Auf der Lieferantenseite (ab Kapitel 5) schreibt die Person den Beitrag im Blatt über dem Termin; Reziproq legt einen Entwurf aus eigenen Unterlagen bereit (LA-01), mit Hilfen „Kürzer“, „Auf Englisch“, „Begründung ergänzen“. Interne Notizen des Lieferanten bleiben `supplier_private`.

## Daten

```sql
CREATE TABLE contribution (
  id uuid PRIMARY KEY, agenda_item_id uuid, side text CHECK (side IN ('buyer','supplier')),
  owner_person_id uuid, kind text CHECK (kind IN ('auto','form','file')),
  form_schema jsonb, answer jsonb, file_ref text, found_ref text, found_at date,
  due_at timestamptz, status text CHECK (status IN ('angefragt','liegt_vor','fehlt','automatisch')),
  link_token text REFERENCES confirm_link(token),
  space text NOT NULL DEFAULT 'shared');
```

## Oberfläche

Agenda-Zeile mit Monogramm je Seite (24 px) und Status-Chip („liegt vor“, „offen · Tom Weber“, „automatisch“). Spiegel der Beiträge (ihr x von y, Gegenüber x von y).
