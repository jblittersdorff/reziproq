# PR-01 Festhalten, Transkript, Protokoll und Bestätigung

Version 1.0 · Kapitel 3 · Paket K3-e · baut auf TE-01, ZQ-01, BL-01, KI-17 · ersetzt Termin-Protokoll (alte Fassung), Knopf „Maßnahme“ · Bildvorlagen: J-Moderation, Termin-Ergebnisse

## Ziel

Im Termin wird festgehalten, was vereinbart ist. Danach ergänzt Reziproq aus dem Transkript, was niemand notiert hat; das Protokoll geht an die Gegenseite, die ihre Zusagen bestätigt.

## Im Termin (Moderation)

Agenda mit aktuellem Punkt und Zeit; Folie; Festhalten mit Knöpfen Zusage, Entscheidung, Frage, Änderung (kein Knopf „Maßnahme“); jeder Punkt trägt Zeit, Person, Agendapunkt und Seite; private Notiz je Punkt. Zusagen erscheinen sofort als Entwurf mit Seite und Frist.

## Danach

1. **Transkript.** Nur wenn `meeting.transcript_enabled`, alle Teilnehmenden zugestimmt haben und eine Betriebsvereinbarung hinterlegt ist (E-K3-7). Nur Text, nie Audio oder Video.
2. **Ergänzungen.** Der Protokoll-Worker vergleicht Transkript und Festgehaltenes und schlägt Ergänzungen vor (Zusage, Entscheidung, offene Frage, Änderung an bestehender Zusage), jede mit Zitat und Uhrzeit, nur für die Käuferseite (E-K3-6).
3. **Ziel-Abgleich.** Je Ziel aus der Vorbereitung: erreicht, teilweise, nicht erreicht, mit Begründung. Nur für euch.
4. **Protokoll teilen.** Ein Mensch prüft Ergänzungen und teilt das Protokoll (Token). Ins geteilte Protokoll gehen keine Zitate und keine internen Punkte.
5. **Bestätigen.** Jede Person beim Lieferanten mit Zusagen bekommt einen Link (BL-01) oder bestätigt in ihrer Akte (LP-01). Bestätigte Zusagen stehen mit Herkunft „Termin <Datum>“ in der Akte.

## Aufbewahrung

Rohtext des Transkripts 90 Tage, dann gelöscht; der Admin wählt 30, 90 oder 180 Tage; länger nur mit Einwilligung beider Seiten (E-K3-7). Das Protokoll bleibt.

## Daten

```sql
CREATE TABLE capture_item (           -- Festgehaltenes und Ergänzungen
  id uuid PRIMARY KEY, meeting_id uuid, agenda_item_id uuid,
  kind text CHECK (kind IN ('zusage','entscheidung','frage','aenderung')),
  text text, owner_person_id uuid, side text, due_at date,
  origin text CHECK (origin IN ('human','transcript')), quote text, quote_at time,
  internal boolean DEFAULT false, accepted boolean, commitment_id uuid);

CREATE TABLE transcript (
  meeting_id uuid PRIMARY KEY, text_ref text, delete_at date,
  consent jsonb,                        -- Zustimmung je Teilnehmer
  space text NOT NULL DEFAULT 'buyer_private');
```

`quote` und `quote_at` werden nie nach `shared` kopiert.
