# QS-01 E-Mail-Versand

Release 0.1 · baut auf PLT-08 (Outbox), PLT-09 · vorgezogen aus 0.2, weil die Bewertungsrunde (SEG-03) Einladungen verschickt

## Ziel

Nutzer bekommen Einladungen, Erinnerungen, Freigabe-Anfragen und Eskalationen per E-Mail. Jede Mail enthält nur einen Titel und einen Link, nie vertrauliche Inhalte.

## Wer darf was

| Rolle | Darf |
|---|---|
| Alle Module | E-Mails nur über diesen Dienst auslösen, als Outbox-Eintrag. |
| Empfänger | Nach Klick auf den Link anmelden und die Seite sehen, sofern ihre Rechte es erlauben. |

## Daten

- **Versand:** Ein Job mit pg-boss liest `outbox_event` und verschickt je Ereignis die passende Vorlage. Jedes Ereignis wird genau einmal verarbeitet, mit Wiederholung bei Fehlern.
- **`email_log`** (`global`, nur für den Betrieb): Zeitpunkt, Vorlage, Status, Hash der Empfängeradresse. Kein Inhalt.
- **Vorlagen** auf Deutsch und Englisch nach `app_user.locale`. Erlaubte Variablen sind nur Vorname, Titel (z. B. „Bewertung Beispiel AG (Demo)“), Frist und Link.
- **Absender:** `noreply@reziproq.de`.
- **Lokal:** Mailpit (MIT-Lizenz) in `docker-compose.yml`. In Staging ab März 2027: AWS SES in Frankfurt.

## Ablauf

1. Ein Modul schreibt in derselben Transaktion wie die Änderung einen Outbox-Eintrag. Er enthält Typ, Empfänger und Link.
2. Der Job baut die Mail aus der Vorlage und verschickt sie.
3. Lokal erscheinen alle Mails in Mailpit unter `http://localhost:8025`.
4. Ein Klick auf den Link führt zur Anmeldung und danach direkt zur Zielseite.

## Fertig, wenn

Je Kriterium ein Test.

- [ ] Eine Testmail kommt in Mailpit an, auf Deutsch und auf Englisch.
- [ ] Ein Test prüft jede Vorlage: Sie nutzt nur die erlaubten Variablen. Weitere Felder lehnt der Dienst ab.
- [ ] Jedes Outbox-Ereignis erzeugt genau eine Mail, auch wenn der Job zweimal läuft.
- [ ] Nach einem Versandfehler wird es erneut versucht. Der Status steht in `email_log`.
- [ ] Der Link führt nach der Anmeldung zur Zielseite.
- [ ] Ohne Recht auf die Zielseite sieht der Empfänger einen klaren Hinweis statt Daten.

## Nicht Teil dieser Funktion

- Einstellungen, welche Mails jemand bekommt
- Zusammenfassungen per Mail
- SES-Anbindung (mit der Testumgebung)
