# KI-01 Modell-Gateway und Kontingent

Release K1 · baut auf allen Modulen bis 1.0 · deckt ab KI-01, KI-02

## Ziel

Jeder Aufruf eines Sprachmodells läuft über ein Gateway in Reziproq. Es erzwingt die Verarbeitung in der EU, wählt das Modell nach Aufgabe, misst Kosten je Kunde und stoppt, bevor ein Budget überschritten wird.

## Wer darf was

| Rolle | Darf |
|---|---|
| Admin | Einstellungen KI ändern, Verbrauch aller Agenten sehen. |
| Käufer: alle mit Zugriff | Kontingent des Monats sehen. |
| Lieferant | Nie. |

## Daten

| Tabelle | Felder | Art |
|---|---|---|
| `model_call` | `id`, `org_id`, `run_id` (optional), `feature`, `model_class` (`small`, `standard`, `synthesis`), `provider`, `model_id`, `region`, `input_tokens`, `output_tokens`, `cost_cents`, `latency_ms`, `created_at` | `org_private` |
| `org_setting` (besteht) | neue Schlüssel: `ai_public_research`, `ai_source_kinds`, `ai_budget_month_cents`, `ai_budget_run_cents`, `ai_max_steps`, `ai_custom_agent_roles`, `ai_custom_agent_approval`, `ai_agent_budget_overrides` (je Agent eine höhere Grenze je Lauf) | `org_private` |

- Das Gateway ist ein Modul im Backend. Kein Code ruft ein Modell an ihm vorbei auf.
- Routing-Tabelle im Code, je Modellklasse: `small` für Extraktion und Klassifizierung, `standard` für Bewertungen und Texte, `synthesis` für Zusammenfassungen über viele Quellen.
- Anbieter in diesem Release: `bedrock_eu` (Claude über das EU-Profil) und `fake` (feste Antworten aus Testdateien, für lokale Entwicklung und Tests). Welcher Anbieter gilt, steht in der Umgebungskonfiguration.
- `region` wird je Aufruf gespeichert. Ein Aufruf außerhalb der EU wird abgelehnt.
- Kosten in Cent, berechnet aus Tokens und einer Preistabelle im Code.
- Bestehende KI-Aufrufe, zum Beispiel „Fragen“, laufen ab diesem Release über das Gateway.
- Startwerte: öffentliche Recherche aus, Budget je Monat 150 €, je Lauf 2,00 €, höchstens 60 Schritte je Lauf, Freigabe durch Admin an.

Budget:

- Ist das Monatsbudget erreicht, startet kein neuer Lauf. Laufende Läufe enden nach dem aktuellen Schritt mit Stand `aborted_budget`.
- Bei 80 % des Monatsbudgets bekommen die Admins eine Aufgabe.
- Überschreitet ein Lauf sein Budget je Lauf oder seine Schritte, endet er mit Stand `aborted_budget` (KI-04).

## Ablauf

1. **Einstellungen KI** (`/einstellungen/ki`): Abschnitte „Daten und Recherche“, „Kosten“, „Eigene Agenten“, rechts der Verbrauch des Monats je Agent und Funktion.
2. „Verarbeitung nur in der EU“ ist immer an und nicht abschaltbar.
3. Ein Agent, der auf Freigabe wartet (KI-09), erscheint oben als nächster Schritt.
4. **Höheres Budget je Agent:** Der Admin setzt für einzelne Agenten, etwa den Strategie-Autor (KI-13), eine höhere Grenze je Lauf. Die Seite zeigt diese Ausnahmen in einer Liste.
5. Die Seite Agenten (KI-04) zeigt das Kontingent des Monats: Läufe und Kosten als Balken.

## Fertig, wenn

Je Kriterium ein Test.

- [ ] Jeder Modellaufruf erzeugt genau eine Zeile in `model_call` mit Kosten und Region.
- [ ] Ein Aufruf mit Region außerhalb der EU wird abgelehnt und protokolliert.
- [ ] Mit Anbieter `fake` laufen alle Tests ohne Netzwerk.
- [ ] Ist das Monatsbudget erreicht, wird ein neuer Lauf abgelehnt, ein laufender endet nach dem aktuellen Schritt.
- [ ] Der Verbrauch je Agent stimmt mit der Summe der Zeilen in `model_call` überein.
- [ ] Kunde A sieht keinen Verbrauch von Kunde B.
- [ ] Der Test-Lieferant sieht weder Einstellungen noch Verbrauch.

## Nicht Teil dieser Funktion

- Eine zweite Route mit Anbietern nur aus der EU (die Seite auf dem Canvas zeigt den Schalter als Zielbild)
- Abrechnung an Kunden
- Eigenes Hosting von Modellen
